# 3D Maze Game

React + TypeScript + Three.js で作られた、一人称視点の 3D 迷路ゲームです。  
ランダム生成された迷路を進み、チェックポイントを回収してゴールを目指します。

## 動作環境

- Node.js 18 以上（推奨）
- npm 9 以上（推奨）

## セットアップ

```bash
npm install
```

## 開発サーバーを起動する

```bash
npm run dev
```

- Vite の開発サーバーが起動します。
- 既定では表示されたローカル URL（通常 `http://localhost:8080`）でプレイできます。

## ビルドする

```bash
npm run build
```

- 本番用ファイルが `dist/` に出力されます。

## ビルド結果をローカル確認する

```bash
npm run preview
```

- `dist/` をローカルサーバーで確認できます。

## 遊び方

### 目的

1. 迷路内のチェックポイントをすべて通過する
2. 右下のゴールマスへ到達する

チェックポイント未回収の状態では、ゴールに到達してもクリアになりません。

### 操作キー

- `↑`: 前進
- `←`: 左回転
- `→`: 右回転
- `H`: ヘルプマップ表示/非表示
- `D`: ヘルプマップ表示中のみ、未訪問領域のデバッグ表示切替

### 画面の見方

- `TIME`: 経過時間
- `GOAL`: `ACTIVE` ならゴール有効、`LOCKED` なら未解放
- `CHECKPOINT`: 通過数 / 総数
- `CLEAR`: クリア時に表示

## 現在の実装仕様（抜粋）

- 迷路サイズ: `10 x 10`
- 迷路生成: 深さ優先探索（再帰）
- 描画: Three.js の PerspectiveCamera
- カメラ移動: 補間アニメーションあり（移動中は矢印入力ロック）
- ビューサイズ: `760 x 380`（`src/game/constants.ts`）
- 壁・柱・床を 3D オブジェクトとして描画
- 柱は壁交点すべてに配置

## 設定値を変更したい場合

主な設定は `src/game/constants.ts` にまとまっています。  
例: 迷路サイズ、カメラ移動時間、ビューサイズ、壁高さ/厚み、色設定など。
